# 面试复盘评估框架

## 轮次标准

在评分和划分优先级前确认轮次。用户提供了非标准轮次时，先根据该轮面试官的身份与问题重点说明采用的评估口径。

| 轮次 | 主要考察重点 |
|---|---|
| 一面 | 基础能力、业务匹配度、逻辑思维、沟通与抗压 |
| 二面 | 宏观视角、潜力、格局、学习能力、职业规划与综合能力 |
| HR 面 | 职业动机、文化契合、意愿度、价值观与稳定性 |

轮次会改变优先级：一面重点关注基础能力和业务匹配；二面重点关注成长性、学习能力和 AI 原生理解；HR 面重点关注动机、文化契合与稳定性。

## 四维评分

每个维度按 10 分制评分。必须同时给出支持得分的证据与限制得分的证据；逐字稿证据不足时降低判断置信度，不以想象补齐。

| 维度 | 判断问题 |
|---|---|
| 项目深度 | 是否真正理解从 0 到 1、关键实现、依赖边界、数据闭环与取舍？ |
| 产品思维 | 是否体现需求洞察、场景抽象、优先级、指标与商业价值意识？ |
| 逻辑表达 | 是否听懂潜台词、结构清楚、证据充分，并能简练解释复杂内容？ |
| 行业潜力 | 是否体现 AI 趋势理解、学习能力、职业规划与持续投入？ |

综合分为四项之和，满分 40 分。

| 评级 | 含义 |
|---|---|
| S | 表现卓越 |
| A | 稳健即战力 |
| A- | 接近 A，有 1–2 项明显短板 |
| B+ | 有亮点，需要针对性打磨 |
| B | 有潜力，需要系统打磨 |
| B- | 整体偏弱 |
| C | 匹配度较低 |
| D | 出现红线问题 |

评级必须与四维得分、岗位要求和轮次表现一致，不机械套用固定基线。

## P0 / P1 / P2

### P0：可能直接影响本轮通过或核心岗位判断

满足下列任一条件且有逐字稿证据时，判为 P0：

- 核心考察维度低于 6 分。
- 出现关键技术或业务事实错误，并影响岗位核心能力判断。
- 面试官追问后明确暴露核心能力缺口、逻辑断裂或关键证据不足。
- 自我评价与实际表现存在明显、可举证的差距。
- 反问暴露出对公司、产品或岗位的重大误解，并在交流中造成负面信号。

追问本身不自动构成问题。中性澄清、自然深入、积极追问和对亮点的继续探索，不得仅因“被追问”判为 P0。

### P1：明显扣分，但通常可以通过专项准备修复

常见情况包括：

- 没有说明策略影响哪个 KPI 或如何验证。
- 失败复盘停留在“后来优化了”，未给出根因。
- 项目叙述只有动作，没有方法论或关键取舍。
- 场景题给出低效的非产品解法。
- 转行或求职动机缺少正向、可信的叙事。
- 长时间单向输出，缺少必要的互动确认。

### P2：表达、完整性或呈现层面的优化项

常见情况包括：

- 结构可以更紧凑，但核心判断成立。
- 数据、案例或背景还可补充，当前缺失不改变主要结论。
- 术语、措辞、篇幅或顺序影响理解效率。

## 逐题状态

- `✅`：结论、结构和证据足以支持岗位判断。
- `🟡`：核心方向成立，推理、证据或表达需要优化。
- `🔴`：存在事实错误、关键缺口或明显偏离考察意图。

状态与优先级分别判断。例如，某题可以标记 `🟡` 并产生一个 P2 表达项；只有符合 P0 证据规则时才列为 P0。

## 常见问题检查表

| 问题 | 检查重点 | 常见优先级 |
|---|---|---|
| 技术颗粒度不足 | 能否解释关键实现、依赖与限制 | P0 或 P1，取决于岗位核心程度 |
| 混淆离线与线上指标 | 是否说清验证层次与业务指标 | 被追问且仍错误时通常为 P0 |
| KPI 意识不足 | 策略是否绑定目标与量化指标 | P1 |
| 根因分析浅 | 是否区分现象、根因、验证与动作 | P1 |
| 方法论提炼弱 | 是否能从项目中提炼可迁移原则 | P1 |
| 场景题解法低效 | 是否优先使用产品机制解决 | P1 |
| 反问质量不足 | 是否结合公司、产品、团队与岗位信息 | 依证据判定 P0–P2 |

## 证据规则

- 优先引用能直接支持判断的短句或完整事实链。
- 将“逐字稿明确说了什么”与“基于这些内容的判断”分开表达。
- 信息不完整时写明限制，不把未提及等同于不会。
- 面试官画像和下一轮预测必须说明依据，并使用“可能”“倾向于”等与证据强度匹配的措辞。
